# ReconcileHub — исправления

## 🔴 Критично
- **app.py падал сразу после логина.** Убран мёртвый дублирующий блок
  логина/навигации, `st.set_page_config()` перенесён в самое начало файла
  (обязательное требование Streamlit). Остался один рабочий путь:
  `login_screen()` → `main_app()`.

## 🟠 Логика / данные
- **Возвраты матчились по-разному** в `core/recon_engine.py` (точное совпадение)
  и в `rrn_page.py` (по вхождению подстроки) → теперь оба места используют
  одинаковую логику "вхождение любого маркера", как и подсказывает UI.
- **`chosen_bank` никогда не заполнялся** → в `rrn_page.py` добавлено поле
  "Название банка", которое реально используется при сохранении в архив.
- **Хардкод `"admin"` в логе** в `epos_page.py` заменён на реального
  пользователя из сессии.
- **`clean_amount_polars`** — улучшена эвристика запятая/точка: теперь
  различает "1,234" (тысячи → 1234) и "1,23" (дробь → 1.23) по числу цифр
  после запятой, а не всегда трактует запятую как десятичный разделитель.

## 🟡 Доступ и настройки
- **Реестр EPOS** теперь закрыт для не-админов и в пункте меню, и явной
  проверкой роли внутри `epos_page.show_page()` (было доступно всем ролям).
- **Общесистемные настройки** (допуск суммы, валюта) теперь хранятся в БД
  (`app_settings`), а не только в `st.session_state` — раньше "сохранённые"
  настройки видел только тот же браузер/сессия.

## ⚪ Безопасность по мелочи
- Пароли теперь хешируются с уникальной солью на пользователя
  (PBKDF2-HMAC-SHA256, 260k итераций) вместо голого SHA-256. Старые
  несоленые хеши по-прежнему проверяются для обратной совместимости.
- `fix_db.py` (аварийный сброс пароля admin) теперь требует
  `ALLOW_ADMIN_RESET=1`, чтобы исключить случайный запуск.
- В `rrn_page.py` добавлена подсказка у ручного поля "Комиссия (%)",
  поясняющая, что это отдельный расчёт "что если" поверх сумм, которые
  уже могут включать комиссию из реестра EPOS по TID — чтобы не путать
  с двойным учётом одной и той же комиссии.

## Не тронуто (нужно ваше решение)
- Роль `accountant`/`auditor` полностью лишена доступа к Реестру EPOS —
  если бухгалтеру нужно видеть комиссии терминалов (не редактировать),
  дайте знать, добавлю режим "только чтение" для этой роли.
- React/TS-версия (`src/...`) не менялась: там RBAC уже сделан правильно
  на уровне `App.tsx`.
